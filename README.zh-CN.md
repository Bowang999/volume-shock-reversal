# 放量反转EMA40｜研究说明

本项目以**费前收益和IC/RankIC**为主要展示，同时保留10bp成本、参数稳健性和增量检验。原多空框架为线性信号加权、多头及空头各100%、每日调仓、次日收盘执行。

经济假设：短期涨跌伴随异常放量，可能包含暂时性买卖压力，随后存在反转。它仍是经济解释，尚未直接识别投资者情绪。

## 原因子

5日复合收益取反，乘当天相对此前5日均量的正向放量幅度，再做EMA40。均量不含当天。随后横截面平均排名、行业和流通市值一次联合中性化、总体标准化。多空各100%意味着目标总敞口200%，收益分母为NAV。

## 最新两项控制

仅加入同样EMA40的纯5日反转和异常换手率。异常换手率=当天换手率/此前20日均换手率-1。每个模型均直接从原始排名一次联合回归到行业、流通市值及指定控制，不重复中性化，本轮不加入残差波动。

联合控制费前年化为13.91%、19.72%，10bp下为5.10%、11.44%；RankIC两段均显著，但后段扣费收益双侧p约0.055，未达5%阈值。原版比纯反转的样本表现更好，收益差异检验尚未达到常用5%标准。不能把正收益或正交关系当成完全独立alpha的证明。

## 可复现范围与边界

- 可以使用仓库内的衍生汇总数据重画全部图，不包含原始个股行情。
- 可以运行合成数据示例验证计算流程；合成结果不是实证图的数据来源。
- 完整市场复跑需要相同口径的行情、行业、股本、股票池和历史数据版本，接口见[data/README.md](data/README.md)。
- 名义窗口从2010开始，受预热和原研究池约束实际从2012开始。2025后已查看，不是严格未触碰样本外。
- 因子来自候选搜索，EMA40经过历史比较后选定；局部125组稳定不能排除整个项目的选择偏差。
- 以前的本地CNE5风格和已有信号控制发现明显重叠，当前两项检验不撤销历史证据，也不是完整正式Barra模型。
- 真实借券、融资、价格限制、容量和源数据历史版本等仍有限制，不声称已验证实盘有效性。
